# 2026-09-16 保存與送出修正

後端版本標記：`20260916-reliability-1`；共用 API 後續補版：`20260916-reliability-2`。

## 行為修正

- 安親送出先確認主要日報保存，再處理通知與待辦。未修改的既有待辦不再逐筆重寫。
- 保存結果不明時保留原始操作編號與送出內容；重新整理、關閉分頁或隔日重開可確認同一次操作。
- 未修改內容不撤回已送出狀態；歷史紀錄依正式送出時間校正顯示，仍保留真正的草稿與送出後修改。
- 附件先保存本機副本，再上傳；重開可恢復待上傳內容。已確認上傳後釋放大型本機副本，保留雲端位置。文件不改寫原始內容。
- 才藝及行政保存途中避免重複操作；未取得確認時保留內容。行政同時修改只合併互不衝突的欄位與項目，重疊修改不默默覆蓋。
- 共用操作回執可跨分頁關閉保存。只有明確未寫入的忙碌回應可有限重試，未知結果先查回執。
- 先前保存結果未知時，後續登入過期仍保留原操作編號；重新登入後繼續確認，避免重複建立資料。
- 寫入試算表的文字不當成公式執行；更新只修改指定欄位，保留未變動內容。
- 工作切換入口、共用程式與離線快取同步更新版本。

## 驗證原則

完整本機驗收執行 `sh tests/release-gate.sh`，包含三工作區、主管／管理員入口、手機與桌面尺寸、附件、草稿、重試、版本衝突及權限。

本輪另以真實 Google 隔離環境驗證文字型別、日報與附件讀回、PDF 成品，以及 8／16 人同時儲存與回執。隔離環境使用合成資料，不等於員工獨立帳號或 iPhone／Android／LINE 實機驗收。

發布後需核對正式版本、來源內容、正式雲端交付五項檢查及跨角色 API，並確認 QA 資料清理。詳細執行編號與結果保留在本機發布紀錄。

## 資料與限制

本次不會將缺少正式送出證據的舊草稿批次改為已送出，也不能恢復過去未留下原檔的附件。本機副本仍取決於瀏覽器允許儲存；失敗必須明確提示，不能假顯示成功。Google 服務排隊仍可能延長等待，通過測試不表示所有裝置與網路情況永遠不會失敗。
