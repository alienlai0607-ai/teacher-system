## 二、安親老師端

### 頁面與操作

以下入口均可開啟且沒有前端錯誤：今日紀錄、備課檔案、我的紀錄、主管評核、追蹤事項、填寫指南、評分標準、帳號與通知、更多功能。

### 已確認規則

- 學科內與學科外不各自強迫必填，但每日送出前至少要有其中一類紀錄。
- 課業指導與班級經營可各建一筆，不會互相覆蓋。
- 課業指導及學科外不要求關聯學生，只保留課後備課回饋。
- 班級經營只有學生特殊狀況時才選學生。
- 學生追蹤已移除出席欄位。
- 親師溝通把共識與後續行動合併，無特殊聯繫時可記錄親自交接孩子。
- 備課檔案不再顯示 50%、67%、83% 等完成度，也不需要主管核准。
- 備課只保留課程類型、課程名稱、使用提醒及至少一份教案或教材附件。
- 已送出的 KPI 修改後會回到待送出，必須再次確認，避免主管看到未確認版本。
- 正式送出有防連點鎖定，相同提示不會重複堆疊。

### 照片與附件

- 成果照片可一次多選，也可分次追加。
- 每張附件有移除按鈕；刪除最後一張時會同步清除舊欄位，避免幽靈附件復活。
- 不再要求重複填寫「這張主管要看什麼／主管請看哪裡」。
- 不以照片相似度阻擋上傳，內容品質改由主管判讀與評分。
- 圖片在瀏覽器端先壓縮；成功上傳後保留即時預覽，重新讀取時由授權 API 取回雲端縮圖。
- 單一附件失敗不會清掉其他成功附件，失敗照片會留在草稿等待正式送出重試。

## 三、安親主管端

以下入口均可開啟且沒有前端錯誤：管理總覽、日報審查、證據中心、班務稽核、學生追蹤、備課檔案、團隊狀態、月度評核、評分標準、雲端日報、系統設定。

- 柏翰與小魚可看跨教室資料；東橋主管只看東橋、北區主管只看北區。
- 證據中心可開啟雲端照片預覽，不直接依賴 Google Drive 公開圖片網址。
- 主管意見與老師回覆以對話形式呈現。
- 評核預設打開最近一筆；只改選單但未按確認時不會誤切資料。
- 老師只能看到已公布評核，主管可繼續處理尚未公布草稿。
- 主管可按老師，再選該老師的備課或紀錄，不把全部資料擠在同一頁。

## 四、才藝部

### 才藝 PT

以下入口均可開啟且沒有前端錯誤：今日上課、備課檔案、家長 APP、鐘點與續報、我的紀錄、使用與規則。

- 正常上課、停課、合作校分流明確；停課可補選，正常課程逾日不可補填。
- PT 鐘點依本堂計薪人數自動套用 2–4 人 500 元、5–7 人 600 元、8–10 人 800 元。
- 黑豹合作校固定 600 元／小時、每堂 1.5 小時 900 元，不計續報獎金，也不要求家長 APP 證據。
- 教室內 PT 需上傳家長 APP 發布完成截圖，缺件不會被誤列為已完成。
- 備課檔案至少要一份教案或教材，可上傳照片、PDF、PPT 或備課影片，不需主管審核。

### 才藝主管與薪資

主管入口均可開啟：主管總覽、備課檔案、工作紀錄、KPI 評分、薪資獎金、人員與排班、雲端日報、制度規則。

薪資入口均可開啟：PT 月結、獎金核准、雲端日報、制度規則。

- 柳丁可查看全部才藝老師，包含黑豹。
- 柳丁的雲端日報也會列出尚未開通、尚無日報的黑豹，清楚標示「待開通／尚未產生正式日報」。
- 月結依老師、月份列出每堂日期、課程、狀態、人數、級距、時數、鐘點費、續報資格及缺件原因。
- 月結單可直接列印給老師核對，不需要行政再次手動 Key 表。
- 共用 API 的網址變數已改名，避免薪資頁認證失敗時出現 `URL is not a constructor`。

## 五、行政美宣

### 老師端

以下入口均可開啟且沒有前端錯誤：今日工作、家長追蹤、專案與交辦、成果與評核、使用說明。

- 今日工作改為一件工作一筆，只填本次結果；未完成時才出現下一步與期限。
- 工作狀態決定必填欄位，不要求重複敘述完成內容。
- 實際新增「行政儲存回歸驗收」後，重新整理仍可讀取。
- 手機長表單可到達底部儲存按鈕；空白送出時會定位第一個未填欄位。
- 修正表單送出後呼叫不存在圖示函式的錯誤，重測無 JavaScript error。
- 試上可登記未來日期，也可貼上 LINE 訊息自動辨識學生、日期、時間、課程、老師與電話。
- 同一學生、日期、課程的重複試上會被阻擋，避免獎金重複計算。

### 主管端

以下入口均可開啟且沒有前端錯誤：主管總覽、家長與獎金、工作紀錄、交辦與專案、月度評核、雲端資料、評分標準。

- 試上轉首次一期並完成繳費，每人 50 元；續報不計此獎金。
- 交辦事項有期限、進度、完成日與證據；同一事項持續更新，不重複建檔。
- 主管評語會進入同月份對話，老師可以回覆。

## 六、穩定性保護

- 圖片選取後先壓縮，降低瀏覽器草稿空間與上傳量。
- 單檔上限統一為 25 MB，選檔前即顯示限制。
- 大檔、失敗檔、成功檔分別處理，不使用整批全成或全敗。
- 草稿同步不會用只有檔名的雲端資料覆蓋本機可用照片。
- 上傳與正式送出都有執行中鎖定，避免連點建立重複檔案或日報。
- 備課建檔前端與後端皆檢查同老師、同類型、同名稱重複資料。
- Apps Script 寫入使用鎖定，避免同時間請求建立雙份資料。
- 正式版已統一更新快取版本；瀏覽器與 Service Worker 不應再混用新舊程式。
